## 🌸 How It Works

The project uses HTML, CSS, and JavaScript together to create the interactive flower experience.

### HTML

HTML creates the basic structure of the flowers and other elements.

```html
<div class="flower">
    <div class="petal"></div>
    <div class="petal"></div>
    <div class="petal"></div>
    <div class="center"></div>
</div>
```

### CSS

CSS creates the visual appearance and animations.

Some of the main CSS concepts used include:

* `transform`
* `transition`
* `animation`
* `@keyframes`
* `border-radius`
* `box-shadow`
* Positioning
* Gradients

Example:

```css
.flower {
    animation: sway 3s ease-in-out infinite;
}
```

### JavaScript

JavaScript provides the interactive functionality.

It can be used to:

* Detect user clicks
* Trigger animations
* Create new flowers
* Change flower properties
* Control interactive effects
* Dynamically manipulate the DOM

---

## 🎨 Customization

You can customize the flowers by modifying the CSS.

### 🌷 Change Flower Colors

For example:

```css
.petal {
    background: pink;
}
```

You can experiment with:

* 🌸 Pink
* 🌹 Red
* 💜 Purple
* 💙 Blue
* 💛 Yellow
* 🧡 Orange

### 🌱 Change Animation Speed

Adjust the animation duration:

```css
animation-duration: 3s;
```

Faster animation:

```css
animation-duration: 1.5s;
```

Slower animation:

```css
animation-duration: 5s;
```
